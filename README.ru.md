# Display Sleep

[English README](README.md)

Минималистичное приложение для строки меню macOS: **один клик по иконке монитора — все дисплеи засыпают**. Сам Mac продолжает работать (Docker, боты, серверы не затрагиваются). Пробуждение — стандартное: любая клавиша или движение мыши.

## Как это работает

- **Левый клик** по иконке `display` (SF Symbols) в строке меню → дисплеи немедленно засыпают. Никаких меню и подтверждений.
- **Правый клик** → маленькое служебное меню: «Запускать при входе» и «Выход».

Сон дисплеев выполняется системной командой **`pmset displaysleepnow`** — это настоящий аппаратный сон панелей, а не имитация чёрным окном. Фолбэк — сервис IOKit `IODisplayWrangler` (свойство `IORequestIdle`): на macOS 26 он возвращает успех, но физически не усыпляет дисплеи, поэтому оставлен только как запасной вариант.

Дополнительно есть защита от «фантомных» пробуждений: некоторые устройства ввода (например, игровые клавиатуры) могут отправить единичное HID-событие через долю секунды после засыпания и мгновенно включить экран обратно. Приложение через 4 секунды проверяет состояние дисплея (`CGDisplayIsAsleep`) и при необходимости повторяет усыпление — до 3 попыток.

## Технические детали

- Swift + AppKit (`NSStatusItem`), без SwiftUI-обёрток и сторонних зависимостей.
- `LSUIElement = true` — без иконки в Dock, приложение живёт только в строке меню.
- Автозапуск — через `SMAppService` (macOS 13+), системный API «Объектов входа».
- Песочница не используется, entitlements не нужны.
- Потребление ресурсов: процесс спит в run loop, CPU ≈ 0%, память ~10–15 МБ.

## Разрешения

**Никаких.** Ни `IODisplayWrangler/IORequestIdle`, ни `pmset displaysleepnow` не требуют прав администратора, Accessibility, Automation или других разрешений. Каждый клик выполняется мгновенно от имени текущего пользователя.

## Сборка и установка

Требуется установленный Swift toolchain (Xcode или Command Line Tools).

```bash
cd /Volumes/ssd-disk/MyProjects/DisplaySleep

# Вариант 1: только собрать (результат в ./build/Display Sleep.app)
./build_app.sh

# Вариант 2: собрать и сразу установить в /Applications
./build_app.sh install
```

После установки запустите:

```bash
open "/Applications/Display Sleep.app"
```

При первом запуске macOS может показать предупреждение о неподписанном приложении (сборка с ad-hoc подписью): **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, либо правый клик по .app → «Открыть».

> Если у вас установлен Xcode, папку проекта можно открыть в нём напрямую (Xcode понимает `Package.swift`): **File → Open…** → выбрать папку проекта → **⌘R** для запуска.

## Автозапуск при входе

**Из приложения:** правый клик по иконке → «Запускать при входе» (появится галочка).
Важно: переключатель работает, когда приложение установлено как .app в `/Applications` — именно там macOS регистрирует объект входа.

**Вручную:** Системные настройки → Основные → Объекты входа → «+» → выбрать Display Sleep.

## Тестирование

1. **Сон дисплеев.** Кликните левой кнопкой по иконке монитора в строке меню — все подключённые экраны должны погаснуть в течение секунды.
2. **Пробуждение.** Нажмите любую клавишу или пошевелите мышью — экраны включаются стандартно, без блокировки сеанса (если включён запрос пароля после сна экрана — это обычная системная настройка, приложение её не меняет).
3. **Mac продолжает работать.** Пока экраны спят:
   - по SSH с другого устройства: `ping`/сессия остаются живыми;
   - проверьте контейнеры: `docker ps` — все работают;
   - Telegram-боты и веб-серверы продолжают отвечать;
   - `pmset -g` покажет, что система не в сне (`sleep 0` до таймаута), уснули только дисплеи.
4. **Автозапуск.** Перезагрузите Mac — иконка должна появиться в строке меню сама.

## Структура проекта

```
DisplaySleep/
├── Package.swift                      # SwiftPM-манифест (macOS 13+)
├── Sources/DisplaySleep/
│   ├── main.swift                     # Точка входа, activation policy .accessory
│   ├── AppDelegate.swift              # NSStatusItem, обработка кликов, служебное меню
│   ├── DisplaySleep.swift             # pmset displaysleepnow + фолбэк IOKit + защита от фантомных пробуждений
│   └── LaunchAtLogin.swift            # SMAppService (автозапуск)
├── Resources/Info.plist               # LSUIElement, bundle id, версии
├── build_app.sh                       # Сборка .app (+ install в /Applications)
└── README.md
```

## Совместимость

- macOS 13 Ventura и новее (проверено на macOS 26, arm64).
- Для macOS 12 и старше замените `SMAppService` на `SMLoginItemSetEnabled` — остальной код не изменится.
